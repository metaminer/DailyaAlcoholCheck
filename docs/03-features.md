# 기능 명세

## 공통

### 디자인 테마
- 다크 테마: 배경 `#0a0c18`, 카드 `#12142a`
- 포인트 컬러: 보라 `#7c6cf7`, 빨강 `#fb7185`, 초록 `#34d399`, 노랑 `#fbbf24`

### Supabase 연동
- CDN으로 로드한 `@supabase/supabase-js` v2 사용
- `js/config.js`에서 URL과 anon key를 전역 변수로 선언
- 모든 CRUD는 Supabase JS 클라이언트를 통해 처리

### 반응형
- 최대 너비 `max-w-lg` (512px) 중앙 정렬
- 모달: 모바일에서 하단 슬라이드, 태블릿 이상에서 중앙 팝업

### 인증
- 모든 페이지 진입 시 `getSession()` 으로 세션 확인
- 미인증 시 `login.html`로 리다이렉트

---

## 로그인 페이지 (`login.html`)

- 이메일 + 비밀번호 입력 폼
- 이미 로그인된 경우 `index.html`로 자동 이동
- 로그인 실패 시 에러 메시지 표시

---

## 달력 페이지 (`index.html`)

### 헤더
- 앱 아이콘 + 타이틀
- 우측: 통계 이동 버튼(막대 차트 아이콘), 로그아웃 버튼

### 이번 달 요약 카드 (2개)

| 카드 | 계산 기준 | 색상 |
|------|-----------|------|
| 음주일 | 해당 월 기록 건수 | 빨강 `#fb7185` |
| 절주일 | 경과일 - 음주일 | 초록 `#34d399` |

### 달력 표시

- 월별 그리드 렌더링
- 일요일: 빨강, 토요일: 파랑, 평일: 흰색
- 오늘 날짜: 보라 링(ring) 표시
- 음주 기록 있는 날: 빨간 점
- 기록 없는 과거 날짜: 초록 점 (절주일)
- 미래 날짜: 점 없음

### 범례
- 🔴 음주 / 🟢 절주

### 기록 입력/수정 모달

날짜 클릭 시 하단 슬라이드 모달 표시.

| 필드 | 입력 방식 | 필수 여부 |
|------|-----------|-----------|
| 음주량 | +/- 버튼으로 1~30 조절 | 필수 (기본값 1) |
| 메모 | 텍스트 입력 | 선택 |

- 기존 기록 있는 날짜 클릭 시 → 기존 값 자동 채움 (수정 모드)
- 수정 모드에서 "삭제" 버튼 노출
- 오버레이 클릭 또는 X 버튼으로 모달 닫기

## 통계 페이지 (`stats.html`)

### 헤더
- 📊 아이콘 + 타이틀
- 우측: 달력 이동 버튼, 로그아웃 버튼

### 요약 카드 (3개)

| 카드 | 계산 기준 | 색상 |
|------|-----------|------|
| 이번 달 음주일 | 현재 월 기록 건수 | 빨강 |
| 총 음주량 | 현재 월 glasses 합계 | 노랑 |
| 음주율 | 음주일 / 경과일 × 100 | 빨강 |

### 월별 음주일 추이 (바 차트)
- 최근 6개월 데이터
- 현재 달 막대: 진한 보라, 이전 달: 연한 보라
- Y축: 음주일 수 (정수 단위)

### 최근 기록 목록
- 최근 12건 날짜 역순 표시
- 날짜 / 요일 / 잔 수 / 메모(있을 경우)
