# 기능 명세

## 달력 페이지 (`index.html`)

### 달력 표시

- 현재 월 기준으로 달력 그리드 렌더링
- 일요일: 빨간색, 토요일: 파란색, 평일: 회색
- 오늘 날짜: 인디고 링(ring) 표시
- 음주 기록이 있는 날짜: 배경색 + 점(dot) + 잔 수 표시

#### 음주량별 색상 코드

| 음주량 | 점 색상 | 배경색 |
|--------|---------|--------|
| 1~2잔 | amber (노란빛 주황) | amber-50 |
| 3~5잔 | orange (주황) | orange-50 |
| 6잔 이상 | red (빨강) | red-50 |

### 월 이동

- `<` / `>` 버튼으로 이전/다음 달 이동
- "오늘로 이동" 버튼으로 현재 월로 복귀

### 이번 달 요약

달력 하단에 3가지 수치 카드 표시:
- **음주일**: 해당 월에 기록이 있는 날 수
- **총 잔**: 해당 월 glasses 합계
- **절주일**: (해당 월 전체 일수) - (음주일)

### 기록 입력/수정 모달

날짜 클릭 시 하단 슬라이드 모달 표시.

| 필드 | 입력 방식 | 필수 여부 |
|------|-----------|-----------|
| 주종 | 6개 버튼 선택 (소주/맥주/와인/막걸리/양주/기타) | 필수 |
| 음주량 | +/- 버튼으로 1~30 조절 | 필수 (기본값 1) |
| 메모 | 텍스트 입력 | 선택 |

- 기존 기록이 있는 날짜 클릭 시 → 기존 값 자동 채움 (수정 모드)
- 수정 모드에서 "삭제" 버튼 노출
- 오버레이 클릭 또는 X 버튼으로 모달 닫기

## 통계 페이지 (`stats.html`)

### 요약 카드 (4개)

| 카드 | 계산 기준 | 색상 |
|------|-----------|------|
| 이번 달 음주일 | 현재 월 기록 건수 | 인디고 |
| 이번 달 총 음주량 | 현재 월 glasses 합계 | 앰버 |
| 이번 달 절주율 | (경과일 - 음주일) / 경과일 × 100 | 그린 |
| 가장 많이 마신 주종 | 현재 월 drink_type 최빈값 | 퍼플 |

### 월별 음주일 추이 (바 차트)

- 최근 6개월 데이터
- 현재 달 막대: 진한 인디고, 이전 달: 연한 인디고
- Y축: 음주일 수 (정수 단위)

### 주종 분포 (도넛 차트)

- 최근 3개월 기록 기준
- 기록 없을 경우 "기록 없음" 메시지 표시
- 우측에 주종별 비율 범례 표시

### 최근 기록 목록

- 최근 12건 날짜 역순 표시
- 날짜 / 요일 / 주종(이모지 포함) / 잔 수 / 메모(있을 경우)

## 공통

### Supabase 연동 방식
- CDN으로 로드한 `@supabase/supabase-js` v2 사용
- `js/config.js`에서 URL과 anon key를 전역 변수로 선언
- 모든 CRUD는 Supabase JS 클라이언트를 통해 처리

### 반응형
- 최대 너비 `max-w-lg` (512px) 중앙 정렬
- 모달: 모바일에서 하단 슬라이드, 태블릿 이상에서 중앙 팝업
